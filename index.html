我没有 Key，怎么办？
  1. Key 就像钱包的钥匙：你在服务商那里开一个 Key，AI 每润色一次就从你的额度里扣一点。
  2. Key 要自己去服务商官网的「开发者控制台 / API Key」页面创建，这个步骤通常要登录和实名，未成年人请让家长或老师帮你操作。
  3. 拿到 Key 第一件事是给对方账户设一个花费上限或余额提醒，然后不要把 Key 发给别人、不要截图分享到群里。
  4. 没有 Key 也完全不影响用：本地引擎是完整的，出 3 个版本、复制、骰子换一批、字数档位都能用，一分钱不花。以后想多一步润色再申请，新手建议从 DeepSeek 或其他国内服务商开始，一般更便宜、网页直连也更友好。

Key 相当于你的钱包，不要发给别人，也不要截图分享。

未成年人请在家长或老师帮助下使用。

本工具不会替你去任何网站申请 Key，也不会加载任何外部脚本或资源；只有你点「一键交给 AI」时，才会在新标签页打开你选的聊天网站。按下「AI 润色」时，你的浏览器才会带着你填的 Key 直连你选的那家服务商。

Key 默认只放在内存里，关掉页面就没了（勾选「记住」才会保存到本机）；使用 AI 润色时，Key 只会发给你选的服务商，不经过本项目的任何服务器。点 AI 润色时，你输入的文字会发给你选的这家服务商。
