# AI 提示词润色台（Prompt Polish Studio）

> 给小白和青少年的提示词工具：一句话生成能直接用的 AI 绘画、像素素材、小游戏提示词，还能把聊天工具生成的小游戏代码粘贴进来当场试玩。

**在线体验**：https://ai-prompt-studio-2zefe7jb8t0.qoder.zone

【截图：首页 / 小游戏生成结果 / 试玩器运行 / 设置窗口】

## 它解决什么问题
想用 AI 画图、做游戏，却不会写提示词；很多工具还要登录、要联网、要 Key。本项目是一个**纯前端单文件网页**：不填 Key 也完整可用，想更精细再接入自己的大模型 Key。

## 功能
- **四个模块**：像素模型、小游戏、AI 绘画、词语扩展。
- **小游戏**：5 种产出目标（可玩小游戏、设计、素材、关卡与数值、场景交互），8 大品类 16 个子类；「可玩小游戏」生成可以发给聊天工具的提示词，让它直接输出单文件 HTML 游戏。
- **AI 绘画**：22 种画风，三个版本逐级递进，8 档画幅比例；时段、情绪、画风互相冲突的词会被过滤。
- **词语扩展**：把一句话扩展成词组，支持骰子换一批。
- **双引擎**：本地引擎（词库、槽位、冲突过滤，不联网）+ 可选的 AI 引擎（用户自带 Key 做润色，可一键还原）。
- **一键交给 AI**：复制提示词，并在新标签页打开 Claude、ChatGPT、DeepSeek、豆包、Kimi、通义千问或自定义网址（点击才打开）。
- **试玩器**：把聊天工具生成的整段 HTML 粘进来，在隔离沙箱里直接运行，游戏代码碰不到页面数据。
- **固定角色图**：上传原创角色图（本机处理、自动抠白底、提取主色），试玩时自动注入游戏，并可下载锁定了角色的 game.html。
- **体验细节**：新手 / 高手模式；选项再点一次即可取消；每页有「重置本页选项」。

## 如何运行
- **在线**：直接打开上面的链接。
- **本地**：下载本仓库的 `index.html`，用 Chrome、Edge 或 Safari 双击打开，不需要安装任何东西。

## 隐私与安全
- 没有后端，没有统计或埋点代码；页面不加载任何外部脚本或资源。
- 上传的角色图只在本机用 Canvas 处理，不上传。
- 填写的 Key **默认只放在内存里，关页面即忘**；勾选「记住」才会保存到本机。使用 AI 润色时，Key 和你的输入只会由浏览器直接发给你所选的服务商，不经过本项目的任何服务器。
- 额度保护：3 秒冷却、输入输出限长、单页最多调用 60 次、一键润色前先确认次数。
- 试玩器用 `sandbox="allow-scripts"` 的 iframe 运行粘贴的代码。
- 未成年人请在家长或老师帮助下使用，并只上传原创角色图。

## 已知限制
- 本地词库有限，认不出的词会在结果下方提示。
- 角色锁定要求聊天工具按提示词读取变量，不同工具遵守程度不同。
- 部分服务商不允许网页直接调用，会显示明确提示。
- AI 润色依赖用户自己的 Key 和额度。
